## Delivered tranche

The candidate freezes the accumulated post-`v1.32.1-rc.1` work: canonical
inbound client identity and backend TLS/mTLS trust, method/header/query
routing predicates with response-header policy and CORS, generic resilience
(admission/retry/circuit) across HTTP/gRPC/FastCGI/stream, the
managed/file-owned configuration-authority model with generated configuration
contracts, the versioned external Admin API (`/api/v1`) and remote CLI, NGINX
assessment/provenance/bounded-include-traversal and migration-corpus tooling,
`jul doctor`/support bundles, HTTP-over-Unix upstreams, a broad hot-reload
programme (admin token/console/plugin-upload/rate-limits/audit-sink/TLS,
cache policy, access-log sinks, OTel sample ratio, egress policy, HTTP/3
Alt-Svc), semantic no-op reload suppression, and this release's own pre-soak
hardening pass (cache-occupancy metrics, `[admin] pprof = false`, and the
soak harness's fault-injection completion). See `CHANGELOG.md`'s
`[2.0.0-rc.1]` entry for the itemized list and
[compatibility.md](../compatibility.md#why-v200-not-v1330-2026-09-17) for why
this is versioned as a MAJOR line.

## Residual risks and follow-ups

- The ≥24-hour final soak (ADR 0005, `docs/soak-procedures.md` Procedure C)
  found a real, pre-existing WASM plugin-pool memory leak during its
  Procedure A pre-flight (fixed in [PR #420](https://github.com/victornife/jul/pull/420),
  merged to `main` as `c3f433d7`) and was then run to completion against
  that fix commit — **not** against this RC tag's original SHA, which still
  has the leak. See [soak-evidence.md](../soak-evidence.md#2026-09-19--final-soak-adr-0005-procedure-c-burn-in-currenttoml-25h-linux)
  for full results: the fix is certified, with two recorded, root-caused,
  low-severity deviations (a sandbox clock anomaly and a 0.0003% plugin
  call-timeout rate) and four open follow-up items (manual host-level
  faults, continuous metrics scraping). A stable `v2.0.0` tag must be cut
  from `main` at or after `c3f433d7`, not from this RC's original SHA.
- Two pre-soak backlog items remain open at this baseline (tracked in
  `docs/audit/2026-09-16-pre-soak-readiness-audit.md`'s backlog table):
  BL-11 (path-scoped Console coverage floors) and BL-12 (external protocol
  conformance lane), neither of which blocks this candidate.
- Cross-protocol conformance/interop evidence (h2spec/Autobahn/ambiguous
  framing corpus) remains open (JUL-AUD-012).
- The stable `v2.0.0` tag, if approved, must be a fresh tag and workflow run
  after the final soak and a separate review — this RC tag is never renamed
  or reused for it.

## Publication decision

The GitHub Release was published as a **prerelease** on 2026-09-17, after the
maintainer independently reviewed the checksums, attestations, and workflow
evidence above. It is not a stable release. The RC tag is immutable and will
not be renamed or promoted. Stable `v2.0.0`, if approved, must be a fresh tag
and workflow run after a separate review, including the final soak.
