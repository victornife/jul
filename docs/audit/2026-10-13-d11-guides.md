## Corrections and boundaries

- Current Go-first ownership does not imply a SQLite/image-codec dependency or
  availability of race detection without a C toolchain. Composition-root line
  counts and gofast dependency proposals are dated historical observations.
- ADR design contexts/timelines stay visible, with current-reading amendments.
  GraphQL remains future work; ADR0013 allows selected experiments without
  activating them. June Beta labels do not replace the feature manifest.
  ADR0005's 1h/4h minimums and #590's pending campaign remain unchanged.
- Canonical inbound address, backend verified peer, HTTP Host and gRPC authority
  are separate identities. UDP affinity follows socket-peer sessions; original
  August deferral wording does not negate subsequently delivered affinity.
- Native gRPC and Unix HTTP use shared consistent-hash selection as well as
  earlier strategies. Backend TLS uses the resolved policy, with platform roots
  as default. Unix support is plaintext HTTP/1.1 and requires a named upstream;
  unsupported TLS/h2c/direct spellings are still rejected.
- Unary transcoding retry uses protobuf idempotency plus the safe HTTP binding;
  UNKNOWN alone does not grant replay. Retired-cache eviction has a nominal
  timer and scheduling delay, not a wall-clock revocation guarantee.
- Audit sinks select their durable destination at event time. `history_keep`
  is independently hot, prunes after Publish and can degrade advisory health.
  A regression mutates this actual consumer back to restart-bound and requires
  the semantic checker to reject it.
- OTel spans omit query from `http.target`, but raw access logs include a
  separate query field. The actual slog schema and per-sink level behavior
  replace invented aliases; Console-tail projection does not redact raw sinks.
  `testdata/otel.toml` needs its collector, trust and writable path prerequisites.

No Go runtime or public vision wording changes in this area. Existing v1/v2
WASM ABI bounds, pooling/generation ownership, body eligibility, CORS/header
ordering, integer affinity vectors and NGINX approximation boundaries are traced
to owning source/tests. No arbitrary-expression routing, body streaming hook,
